### 🌟 项目简介

**樱舞次元 (SAKURA DANCE)** 是一个全自动聚合全网二次元热舞视/频的开源项目。

- 🎬 **海量收录**：现收录 **3万+ 部** 精彩内容，每周持续更新。
- 🚀 **极速稳定**：部署于 G 口宽带高防服务器，全天候稳定运行，拒绝 404。
- ⚙️ **全自动后台**：自带接口版，支持自定义修改对外接口地址、站点信息。
- 📊 **数据统计**：全新统计报表，请求数据一目了然。
- 🔐 **用户系统**：支持注册登录、资料与头像、个人简介、点赞互动等丰富功能。

---

### 🛠️ 环境要求

- **Web 服务器**：`Nginx` 或 `Apache`
- **运行环境**：`PHP 5.6` 及以上
- **数据库**：`MySQL 5.6` 及以上

---

### 🚀 搭建教程

1. **自备环境**：准备一台服务器/VPS 和一个域名。
2. **上传程序**：将本项目源码上传至网站根目录。
3. **安装引导**：访问首页，按照页面提示完成安装即可。
